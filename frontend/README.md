# frontend

OfferForge 的 **Web 前端**:面经浏览/筛选界面与模拟面试界面。未来可能接入微信小程序,支持移动端轻量访问。

## 职责

- 面经列表展示。
- 多维筛选交互:按公司、出现频率、技术栈(AI / Java 后端 / 前端)。
- 查看面经与对应答案。
- 模拟面试:展示随机题目,接收用户作答。
- 预留微信小程序接入可能,前端选型需考虑 Web 与小程序的复用关系。

## 状态

🚧 空骨架。Web 前端已确定采用 React + Vite + TypeScript;未来接入微信小程序时优先评估 Taro + React。详见 [../docs/tech-stack.md](../docs/tech-stack.md)。
