# 需求与功能清单

> 本文档记录 OfferForge 的产品需求,作为开发与技术选型的依据。随项目推进持续更新。

## 项目目标

收集互联网大厂面经,辅助用户准备面试,**核心关注 AI 相关面试**,同时覆盖 Java 后端、前端等技术栈。

## 功能模块

### 1. 面经收集(爬虫)

- 从内容平台拉取用户分享的面经:
  - 牛客
  - 小红书
  - (可扩展更多平台)
- 采集到的原始内容需要清洗、结构化。

### 2. 归类与存储

- 按**公司**归类。
- 按**技术栈**打标签:AI / Java 后端 / 前端 /(可扩展)。
- 持久化到数据库。

### 3. 浏览与筛选(前端)

- 网页界面展示面经列表。
- 支持多维度筛选:
  - 按公司
  - 按出现频率(高频题)
  - 按技术栈
- 查看面经对应的**答案**。

### 4. 模拟面试

- 随机生成一组面试题(可按技术栈/公司圈定题库)。
- 用户作答。
- (待定)作答后的反馈/评分机制。

## 用户视角

- 用户可指定关注的技术栈(AI / Java 后端 / 前端)。
- 用户可按公司、频率等筛选并查看面经与答案。
- 用户可进行模拟面试练习。
