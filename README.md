# OfferForge

收集互联网大厂面经、辅助面试准备的全栈项目,核心关注 **AI 相关面试**,同时支持 Java 后端、前端等技术栈。

## 核心功能

- **面经收集**:通过爬虫从牛客、小红书等内容平台拉取面经。
- **归类与存储**:按公司归类,持久化到数据库。
- **浏览与筛选**:网页界面,支持按公司、出现频率、技术栈(AI / Java 后端 / 前端)等维度筛选,并查看对应答案。
- **模拟面试**:随机生成面试题,用户作答。

详见 [docs/requirements.md](docs/requirements.md)。
